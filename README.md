# CodeAtlas

CodeAtlas is a system for creating and maintaining a structured, reversible description of a codebase. It serves as a two-way bridge between human intent and source code, designed to be driven by Large Language Models (LLMs).

## Core Concept: The Intelligence Engine

CodeAtlas acts as the "Sensory System" for AI coding agents. Its primary job is to **understand** a codebase and present it in a format that LLMs can process efficiently and cheaply.

It achieves this through:
1.  **Deep Indexing:** Parsing code to build a hierarchical tree of files, classes, and functions.
2.  **Machine Core:** Generating a compressed, token-efficient JSON representation of the project structure.
3.  **Intelligent Context:** Automatically finding dependencies and "hydrating" only the relevant parts of the code into the context for a specific task.

## Workflow

CodeAtlas supports both manual and automated workflows.

### 1. Planning & Context Generation
The `atlas plan` command is the heart of the system. It takes a high-level goal and a target file/symbol.

```bash
atlas plan --goal "Refactor the login logic" --target "src/auth.py"
```

It outputs:
*   `bundle.json`: A complete, machine-readable context bundle.
*   `prompt.txt`: A ready-to-paste prompt containing the Machine Core and the user's goal.

### 2. Execution (Current & Future)

Currently, CodeAtlas includes built-in execution capabilities for standalone use:
*   **`atlas apply`:** Applies JSON change packets generated by an LLM.
*   **`--with-llm`:** Optionally calls an LLM API directly to generate changes.

**Future Vision:** These execution responsibilities will be migrated to a dedicated sister project, **BridgeAI**. CodeAtlas will focus purely on intelligence and context generation, while BridgeAI will handle the "Motor System" (API calls, file modifications, testing, and git operations).

## Key Features

*   **Stateless Design:** All state is local. The workflow is resilient to interruption.
*   **Causal Proposals:** Generates hierarchical change proposals that link primary changes to their dependent updates, enabling effective review.
*   **Human-Readable Reports:** Produces concise YAML reports (`proposal.yaml`) for human assessment of AI-proposed changes.
*   **Automated Summarization:** Keeps the project specification in sync with the code via `atlas summarize`.

## Installation & Development

CodeAtlas is a standard Python package.

### 1. Setup Environment
It is recommended to use a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -e .  # Editable install for development
```

### 2. Build for Distribution
To create a `.whl` file for installation in other projects (like BridgeAI):

```bash
pip install build
python -m build
```

This will create `dist/codeatlas-0.1.0-py3-none-any.whl`.

### 3. Install Elsewhere
To use CodeAtlas in another project:

```bash
pip install /path/to/CodeAtlas/dist/codeatlas-0.1.0-py3-none-any.whl
```
